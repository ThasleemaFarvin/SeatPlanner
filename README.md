## How to Run

**Requirements:**
- Python 3.x

**Steps:**

1. Clone or download the project repository.
2. Open the project folder in VS Code or any Python IDE.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

## Features That Work

1. **Student Management:** Add and store student details, including student ID, name and branch.
2. **Room Management:** Create and manage examination rooms with specified rows and columns.
3. **Backtracking-Based Seat Allocation:** Automatically allocate students while ensuring that students from the same branch are not seated adjacent to each other.
4. **Seating Arrangement Display:** Display room-wise seating arrangements in a structured format.
5. **Student Lookup:** Search for a student and identify their allocated room and seat.
6. **Door Sheet Generation:** Generate a door sheet containing student seating information.
7. **Data Persistence:** Store student and room information using JSON files.
